A one-line review of the most boring everyday object I could name: the doorstop. Its whole job is holding a door open, and its reward is getting kicked across the room for doing it.

## Run it

```sh
python3 main.py
```

Writes the entry (one line, at most 200 characters, plain ASCII) to `/output/entry.txt`. Python standard library only, no dependencies.
